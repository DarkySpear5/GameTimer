# GameTimer
Helps keeping a tracking of your game time even offline. It doesn't require any internet connection to set up and it's lightweight. Ideal for keeping a track of everygames you're running even for completionist. Still in alpha phase. Made with the help of Claude AI.

#Doesn't work if you install it in program files x86 since it requires it to have admin control. Even if you launch it with admin right, the apps might have bugs. Better just install it somewhere else.
